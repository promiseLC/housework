# 家务计酬后端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现 OpenAPI 0.1.2 全部后端闭环并用真实 MySQL/MariaDB 集成测试验证。

**Architecture:** FastAPI 同步接口、SQLAlchemy 2 会话事务、InnoDB 行锁。业务状态、工资、结算明细、幂等响应及审计在同一事务提交，预览只读。

**Tech Stack:** Python 3、FastAPI、Pydantic 2、SQLAlchemy 2、PyMySQL、Alembic、Argon2id、PyJWT、pytest、httpx、MariaDB。

## Global Constraints
- 仅本工作树 backend/ 与本计划可写；不改 frontend，不推送、不部署、不改历史。
- 账号 username，金额整数分 1..100000000；时间 UTC ISO 8601。
- 本地提交身份 开发小组（本地开发） <household-pay@localhost>。
- SQLite 不作为 MySQL 验证；安装或启动真实数据库失败必须停止并报告。
- 付款方本人可预览和标付款；预览不占锁、不写库；不支持冲正、部分付款或自动抵扣。

## 文件结构与数据设计
- backend/pyproject.toml、.env.example、README.md：依赖、无线上密钥配置、启动迁移测试说明。
- backend/app/core/{config,db,errors,security,idempotency}.py：环境、事务、统一错误、令牌与幂等。
- backend/app/models.py：13 张 InnoDB 表；users、refresh_tokens、households、household_members、household_invites、chore_types、chore_tasks、task_review_events、wage_entries、payments、payment_items、idempotency_keys、audit_logs。
- backend/app/{schemas,presenters,main}.py 与 app/api/{auth,households,chores,payments}.py：输入验证、输出、路由和按域服务。
- backend/alembic/env.py、versions/0001_initial.py：空库迁移及显式版本化表定义。
- backend/tests/{conftest,test_infrastructure,test_auth_households,test_chores,test_payments,test_concurrency,test_contract}.py：真实 MySQL 行为和契约检查。
- backend/scripts/smoke.py：真实 HTTP 冒烟。

生成列：household_members.active_user_id = IF(left_at IS NULL,user_id,NULL) 唯一；chore_types.active_name = IF(is_active=1,name,NULL)，家庭+active_name 唯一。邀请使用 inviter 用户行串行化且 pending_inviter 生成列唯一，过期惰性清理。wage_entries.task_id 唯一；payment_items 仅(payment_id,wage_entry_id)唯一。金额加 CHECK；结算合计用 BIGINT 避免多笔 INT 溢出。

## 事务、锁与幂等
所有业务写先锁家庭行，验证 active，再锁目标任务/模板/结算与按 UUID 排序的工资；与解绑使用相同家庭锁避免漏拦截。邀请接受先读取邀请定位参与者，再按 UUID 顺序锁两用户、重读邀请加锁，检查双方绑定后一次建家庭。刷新令牌哈希落库，行锁轮换。
Idempotency-Key 8..64，以(user_id,key)主键 INSERT 争抢；同键并发等待首事务完成，比较 method/path/规范 JSON SHA256。成功响应与业务一并保存；业务错误回滚整个事务（不缓存失败，不留半状态）；重试可再次执行，数据库约束冲突统一409。审计只追加，令牌/密码/明文邀请码不进 payload。
